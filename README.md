# DofousXen

Idle / autobattler inspiré de DOFUS, jouable dans le navigateur (PC et mobile).

- `game/` : le jeu (HTML + JS, sans dépendance)
- `tools/` : scripts d'import des données depuis [DofusDB](https://dofusdb.fr)

Projet de fan gratuit et non commercial, sans lien avec Ankama Games.
DOFUS, ses noms, images et contenus sont la propriété d'Ankama Games. Données : DofusDB.
